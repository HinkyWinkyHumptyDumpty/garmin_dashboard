Anleitung für die eigene Kopie

Dein Notfall-Code

Mit diesem Code setzt du dein Passwort zurück, falls du es vergisst. Es gibt keinen anderen Weg – E-Mails verschickt Tagesform nicht.

Speichere ihn im Passwort-Manager oder schreib ihn auf. Er gilt, bis du einen neuen erstellst.

Garmin verbinden

Tagesform liest deine Daten mit deinem persönlichen Garmin-Schlüssel – nur lesend, nur deine eigenen.

  1. Öffne im Browser die Seite Personal API Key in Garmin Connect und melde dich an.
  2. Wähle Create Key, lies und akzeptiere Garmins Bedingungen.
  3. Wähle die längste Laufzeit – danach brauchst du einen neuen Schlüssel.
  4. Kopiere den Schlüssel sofort – Garmin zeigt ihn nur ein einziges Mal.

Der Schlüssel wird verschlüsselt gespeichert und nur benutzt, um deine Daten bei Garmin abzuholen. Ändern oder entfernen kannst du ihn jederzeit unter Profil → Konto.

Kein Garmin-Schlüssel? Konto wieder löschen
